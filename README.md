# KUN.UZ Backend

A Spring Boot news API with multilingual articles and user registration.

## Technologies
Java, Spring Boot, PostgreSQL, Spring Data JPA, Maven, Lombok.

## Features
- Profile management, filtering, and password change
- Registration and login using email or phone
- SMS and email verification with resend and expiry
- Personalized welcome emails
- Article creation, publishing, filtering, and view/share counters
- Multilingual categories, regions, and article types
- SMS and email history
- Integration with a separate SMS service

## Notes
JWT authentication, role enforcement, and several remaining news features are still in progress.
